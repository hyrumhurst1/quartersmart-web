Anthropic stopped Claude subscriptions from running third-party agents: what happened and what changed

For a few weeks, agent tools like OpenClaw could no longer run on a Claude subscription. Here is what changed on April 4, why Anthropic did it, what changed again in May, and the lesson for any tool your work depends on.

The short version

  • Anthropic said that from April 4, 2026, Claude subscriptions would stop covering third-party agent tools such as OpenClaw, an open-source personal agent.
  • People could keep using those tools, but had to pay for that usage separately, through pay-as-you-go extra usage or a separate API key.
  • Anthropic said its subscriptions were not built for how these tools use Claude.
  • On May 13, 2026, Anthropic announced that subscriptions could power third-party agents again, through a separate monthly credit billed at API rates.
  • The lesson for any business: know what each AI tool runs on, and whose account and terms it depends on.

What changed on April 4

Anthropic told subscribers that from noon Pacific on April 4, 2026, their Claude subscription limits would no longer cover third-party harnesses: tools built by other people that run Claude on your behalf. OpenClaw, an open-source personal agent, was the first. Anthropic said the rule applied to all third-party harnesses and would roll out to more of them.

Nothing was switched off. People could keep using these tools, but the usage was billed separately: pay-as-you-go extra usage on the Claude account, or a separate API key. That is why the verdict at the time was Act now for anyone running an agent this way. Without a change to billing, the agent would stop working the next day.

Why Anthropic did it

Boris Cherny, who leads Claude Code at Anthropic, said the company's subscriptions were not built for the usage patterns of these third-party tools, and that it had to manage growth to keep serving customers sustainably.

Our read: a flat monthly subscription works because most people use it in bursts. An agent that runs all day on the same subscription uses it very differently.

What changed in May

On May 13, 2026, Anthropic announced that subscriptions could run third-party agents again, with a catch. That usage draws from a separate monthly credit, billed at API rates, that does not roll over. When it runs out, you buy more credit or turn on extra usage.

What it means for your business

If an AI tool matters to your work, know three things about it: which model it runs on, whose account pays for it, and whose terms it depends on. A tool that rides on someone else's subscription can change price overnight, even when the tool itself does not change at all.
