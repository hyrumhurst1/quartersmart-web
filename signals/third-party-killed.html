Anthropic cut off third-party Claude resellers: what happened and what to do

Anthropic shut off the resellers that sold discounted Claude API access, including OpenClaw. Here is why it happened, who was affected, and what the options were for teams that relied on them.

By Hyrum HurstPosted Apr 3, 2026Updated Sep 27, 2026

Book a 20-minute call

The short version

  • In early April 2026, Anthropic revoked API access for third-party services that resold Claude at deep discounts, including OpenClaw and ClaudeProxy.
  • Resellers had charged $100 to $200 a month for use that cost $3,000 to $5,000 in compute. Users moving to the direct API faced up to 50 times their old cost.
  • Anthropic's terms prohibit API reselling. There was no warning and no migration period.
  • If you relied on a reseller, the options were Claude Pro, the direct API, or another provider. Keep a fallback for any tool your work depends on.

On April 4, 2026, dozens of third-party Claude services stopped working. There was no warning and no migration period, only a message: "Access revoked."

Anthropic shut down the resellers, including OpenClaw and ClaudeProxy, that sold access to Claude's API at deep discounts. Developers and power users who relied on them faced a cost increase of up to 50 times overnight.

Why Anthropic did it

The resellers charged $100 to $200 a month for "unlimited" Claude access. Each heavy user consumed $3,000 to $5,000 in actual compute. The resellers covered the gap with venture capital, betting they could lock in users before Anthropic acted.

Who was affected

  • OpenClaw. The largest reseller, with about 15,000 active users. It shut down entirely within 24 hours of the cutoff.
  • ClaudeProxy. Offered "unlimited Opus" for $150 a month. Its API keys were revoked on April 4.
  • Discord bots. Hundreds of bots offering Claude access in Discord servers stopped at the same time.
  • Small SaaS products. Startups that built their product on resold Claude access lost a core feature.

How developers reacted

The response on X, Reddit and Hacker News was fast and angry. The top post on r/artificial, "Anthropic just pulled the rug on 50,000 users," reached 8,000 upvotes in 12 hours. Developers who had built workflows on these services had to rebuild them.

The most common complaints:

  • "No warning." Users woke up to dead API keys with no advance notice.
  • "No migration path." Anthropic did not offer discounted direct API access as a transition.
  • "They're punishing users for their own pricing failure." If the API was priced unsustainably, the argument goes, that is Anthropic's problem, not the users'.

Could the resellers fight back?

Probably not. Anthropic's terms of service prohibit API reselling. The resellers were always operating in a gray area, most knew it, and their own terms disclaimed liability for exactly this scenario. Some users have explored class actions against the resellers, not Anthropic, for failing to disclose the risk. As of this writing, none has been filed.

OpenAI's response

Within hours, OpenAI's developer relations team began courting displaced Claude users, offering migration credits, onboarding support and a pointed message: we don't do this to our developers.

OpenAI still allows full third-party API access. Any developer can build on GPT-4o, GPT-5.4 or any model in its lineup, with no restrictions beyond standard rate limits.

The story that stuck was simple: Anthropic restricts, OpenAI opens up. Anthropic would argue it is protecting the sustainability of its platform.

Two different bets

Anthropic is betting that controlling access to its most capable models builds a sustainable business. OpenAI is betting that open access drives adoption, and adoption wins.

What this means going forward

This is about control as much as price. Anthropic is building an ecosystem where it decides who gets access to Claude and at what price. OpenAI and Google run more open marketplaces.

The Mythos restriction to 40 organizations under Project Glasswing looks like part of the same pattern. Anthropic is betting that controlled access is the right model for frontier AI. Whether developers, and the market, agree is still open.
