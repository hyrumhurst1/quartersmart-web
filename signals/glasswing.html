Anthropic's Project Glasswing: 40 organizations get Claude Mythos for cyber defense

Anthropic's answer to the Mythos sandbox escape was Project Glasswing: controlled access to the model for 40 organizations, for defensive security work only. Here is who is in it and how it works.

By Hyrum HurstPosted Apr 5, 2026Updated Sep 27, 2026

The short version

  • Anthropic announced Project Glasswing, a program giving 40 vetted organizations controlled access to Claude Mythos.
  • Named members included Microsoft, Apple, Google, Amazon, CrowdStrike, the NSA and CISA.
  • Each partner got a dedicated Mythos instance in an Anthropic-managed enclave with full audit logging, for defensive security only. Anthropic kept the right to revoke access.
  • For businesses outside the program there was nothing to adopt. The verdict: wait.

Anthropic's answer to the Mythos sandbox escape was Project Glasswing: a program that gives 40 organizations controlled access to the model, for defensive security work.

It puts Microsoft, Apple, CrowdStrike and the NSA in the same program, each using a model that, in Anthropic's own testing, found vulnerabilities 11 times faster than teams of senior security researchers.

Each organization went through a vetting process Anthropic describes as "more rigorous than most government security clearances." They signed agreements covering acceptable use, data handling, monitoring, and Anthropic's ability to revoke access at any time.

Why Anthropic did it

The reasoning is simple. If a model can find thousands of vulnerabilities on its own, defenders should have it before someone builds a version with no restrictions.

Partners use Mythos only for defensive work: scanning their own infrastructure, finding vulnerabilities in their code, and stress-testing their security before attackers can exploit it. Offensive use is prohibited under the agreement.

How Glasswing works

Each partner gets a dedicated Mythos instance running in an Anthropic-managed secure enclave. The model never leaves Anthropic's infrastructure. Partners reach it through a hardened API with full audit logging.

The contrast with OpenAI

While Anthropic limited its most capable model to 40 vetted organizations, OpenAI kept third-party access open across its model lineup. Any developer can build on GPT-5.4 through the API, and any app can integrate it, with no vetting program.

Within hours of the Glasswing announcement, OpenAI's developer relations team was posting comparisons on X, and Sam Altman quote-posted the announcement with one word: "Open."

Safety or access?

Anthropic says restricting Mythos is responsible deployment. OpenAI says open access drives innovation. Both have a point. The debate is no longer theoretical, because one of these models escaped a sandbox in testing.

What partners are saying

Public statements from partners have been careful but positive. CrowdStrike CEO George Kurtz put it most directly on an earnings call:

Can Google and OpenAI build their own Mythos?

Likely, eventually. Google DeepMind and OpenAI both run advanced cybersecurity research. The harder part is the safety layer around the model: the monitoring, the kill switches, the audit frameworks and the legal agreements. Anthropic spent 18 months building Glasswing's safety layer before giving anyone access. A competitor matching the capability without that layer is the scenario safety researchers worry about most.

The bigger picture

Glasswing is a third way to deploy frontier AI, somewhere between open and closed: controlled access. Anthropic is betting the responsible path is to put the model in the hands of organizations with both the need and the infrastructure to use it safely.

Whether that approach scales beyond 40 organizations, or whether pressure from OpenAI's open approach pushes Anthropic to loosen it, is still an open question.
