Free Claude and GPT access for students: GitHub Copilot Pro and ChatGPT Edu

As of April 2026, verified students could get GitHub Copilot Pro, which includes Claude, free through the GitHub Student Developer Pack, and many could get ChatGPT Edu through their university. Here is how to apply.

The short version

  • As of April 2026, the GitHub Student Developer Pack gave verified students GitHub Copilot Pro free. Copilot Pro normally costs $10 a month and lets you use several models, including Anthropic's Claude.
  • ChatGPT Edu was available to students at participating universities, through the school's own sign-in.
  • GitHub verification took a school email, student ID, enrollment letter or transcript.
  • Programs and prices change. Check the current terms on GitHub and OpenAI before you apply.

If you are a student, you may already qualify for paid-tier AI tools at no cost. Between GitHub's Student Developer Pack and OpenAI's education program, verified students can get paid-tier access to Claude and GPT models for free. Here is how to get it.

GitHub Copilot Pro through the Student Developer Pack

The GitHub Student Developer Pack includes GitHub Copilot, which runs on several models, including Anthropic's Claude. As a verified student, you get GitHub Copilot Pro free: code completion in your editor, chat, and a choice of models.

What you get: GitHub Copilot Pro, which includes Claude

AI code completion, chat assistance, pull request summaries and code explanations, with Claude among the models you can pick. Copilot Pro normally costs $10 a month. It is free for verified students.

How to apply

  1. Create a GitHub account. If you don't have one, sign up at github.com/join. Use your school email if you can. It speeds up verification.
  2. Apply for GitHub Education. Go to education.github.com/discount_requests/application and click "Get student benefits."
  3. Verify your student status. You'll need one of: a school email address, a student ID photo, an enrollment letter or a transcript.
  4. Activate Copilot Pro. Once approved, go to github.com/settings/copilot and turn on Copilot. It is free on your student plan.

Apply for the GitHub Student Pack

What else is in the Student Developer Pack?

Dozens of other developer tools and services, free for students while they are enrolled. The list changes often. See the current one at education.github.com/pack.

ChatGPT Edu through your university

OpenAI runs its own education program. Through ChatGPT Edu, universities can give students more capable ChatGPT access than the free plan, with higher limits and data analysis tools.

What you get: ChatGPT Edu

OpenAI's paid models, data analysis, web browsing, custom GPTs and higher message limits than the free plan. Available through participating universities.

How to get ChatGPT Edu

  1. Check whether your university participates. Visit openai.com/chatgpt/education to see if your school offers ChatGPT Edu. Participating schools include ASU, Columbia, Wharton and Oxford.
  2. Sign in with your university credentials. If your school participates, you sign in through its single sign-on. There is no separate application, because the university handles the licensing.
  3. If your university doesn't participate yet. Ask your IT department or a professor to look into ChatGPT Edu. In the meantime, the free plan of ChatGPT gives you the current free model, and the free version of GitHub Copilot includes a limited number of completions and chats.

Other free AI tools for students

Claude and GPT get the attention, but a few more free tools are worth knowing:

  • Google Gemini. Google's free Gemini app. No student verification needed. gemini.google.com
  • Microsoft Copilot. Free with any Microsoft account. copilot.microsoft.com
  • Perplexity. Free, research-focused AI that shows its sources. perplexity.ai
  • Claude.ai free plan. Anthropic offers limited free access to Claude. claude.ai
  • JetBrains IDEs. Free educational licenses for students. jetbrains.com/education

Use more than one

You can use GitHub Copilot, ChatGPT Edu and the free plans at the same time. Different tools are better at different things, so try the same task in two of them and keep the one that does it better.

What to have ready

  • School email. Not required, but it speeds up GitHub verification.
  • Student ID. A photo of your current student ID card.
  • Proof of enrollment. An acceptance letter, transcript or enrollment verification letter.
  • GitHub account. Free, and quick to create.
  • Age 13 or older. GitHub's minimum age.

GitHub reviews each application, so approval times vary. ChatGPT Edu access is immediate if your university already participates.
