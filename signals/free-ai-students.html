Free Claude and GPT access for students: GitHub Copilot Pro and ChatGPT Edu

As of April 2026, verified students could get GitHub Copilot Pro, which includes Claude, free through the GitHub Student Developer Pack, and many could get ChatGPT Edu through their university. Here is how to apply.

By Hyrum HurstPosted Apr 4, 2026Updated Sep 27, 2026

The short version

  • As of April 2026, the GitHub Student Developer Pack gave verified students GitHub Copilot Pro free. It includes Claude-powered code assistance and normally cost $19 a month.
  • ChatGPT Edu was available to students at participating universities, through the school's single sign-on.
  • GitHub verification took a school email, student ID, enrollment letter or transcript. Most applications were approved within minutes to hours.
  • Programs and prices change. Check the current terms on GitHub and OpenAI before you apply.

If you are a student, you may already qualify for paid-tier AI tools at no cost. Between GitHub's Student Developer Pack and OpenAI's education program, verified students can get paid-tier access to Claude and GPT for free.

Here is how to get it.

GitHub Copilot Pro through the Student Developer Pack

The GitHub Student Developer Pack includes GitHub Copilot, which runs on models including Anthropic's Claude. As a verified student, you get GitHub Copilot Pro free, with Claude-powered code assistance, chat and more.

What you get: GitHub Copilot Pro, which includes Claude

AI code completion, chat assistance, pull request summaries and Claude-powered code explanations. Normally $19 a month, free for verified students.

How to apply

  1. Create a GitHub account. If you don't have one, sign up at github.com/join. Use your school email if you can. It speeds up verification.
  2. Apply for GitHub Education. Go to education.github.com/discount_requests/application and click "Get student benefits."
  3. Verify your student status. You'll need one of: a .edu email address, a student ID photo, an enrollment letter or a transcript. GitHub uses SheerID for verification, and most applications are approved within minutes.
  4. Activate Copilot Pro. Once approved, go to github.com/settings/copilot and enable Copilot. It is free on your student plan.

Apply for the GitHub Student Pack

What else is in the Student Developer Pack?

More than 100 tools and services, including free domains from Namecheap, $200 in DigitalOcean credits, Canva Pro, JetBrains IDEs, MongoDB Atlas credits and Notion Pro. It is free for students. See the full list at education.github.com/pack.

ChatGPT Edu through your university

OpenAI runs its own education program. Through ChatGPT Edu, universities can give students enhanced ChatGPT access, including GPT-4o and advanced analysis tools.

What you get: ChatGPT Edu

GPT-4o access, Advanced Data Analysis, web browsing, custom GPTs and higher message limits. Available through participating universities.

How to get ChatGPT Edu

  1. Check whether your university participates. Visit openai.com/chatgpt/education to see if your school offers ChatGPT Edu. Participating schools include ASU, Columbia, Wharton and Oxford.
  2. Sign in with your university credentials. If your school participates, you sign in through its single sign-on. There is no separate application, because the university handles the licensing.
  3. If your university doesn't participate yet. Ask your IT department or a professor to look into ChatGPT Edu. In the meantime, the free tier of ChatGPT gives you GPT-4o mini, and the free version of GitHub Copilot includes limited GPT-powered completions.

Other free AI tools for students

Claude and GPT get the attention, but a few more free tools are worth knowing:

  • Google Gemini. The free tier includes Gemini 2.0 Flash with generous limits. No student verification needed. gemini.google.com
  • Microsoft Copilot. Free with any Microsoft account. Uses GPT-4o. copilot.microsoft.com
  • Perplexity AI. Free, research-focused AI with citations. perplexity.ai
  • Claude.ai free tier. Anthropic offers limited free access to Claude Sonnet. claude.ai
  • JetBrains AI Assistant. Free for students through the Student Developer Pack. jetbrains.com/education

Use more than one

You can use GitHub Copilot, ChatGPT Edu and the free tiers at the same time, and different tools are better at different things. A reasonable split: Claude for careful reasoning, GPT for creative tasks, and Gemini for research with source citations.

What to have ready

  • School email (.edu). Not required, but it speeds up GitHub verification.
  • Student ID. A photo of your current student ID card.
  • Proof of enrollment. An acceptance letter, transcript or enrollment verification letter.
  • GitHub account. Free, and it takes two minutes to create.
  • Age 13 or older. GitHub's minimum age.

Most GitHub Student Pack applications are approved within minutes to hours. ChatGPT Edu access is immediate if your university already participates.
